## Project Description
**Safe Exm** est une extension Chrome (Manifest V3) furtive et automatisée d'aide à la résolution de quiz en ligne. Elle analyse dynamiquement le DOM, interroge des modèles de langage (LLM) avec gestion de secours multi-fournisseur (multi-provider fallback), et injecte ou surligne les réponses de façon indétectable.

## Architecture
Le projet contient les principaux composants suivants :
- [manifest.json](file:///home/omni/Code/Elearning_Ext/manifest.json) : Point d'entrée de l'extension Chrome (Manifest V3).
- [loader.js](file:///home/omni/Code/Elearning_Ext/loader.js) : Script léger de détection dynamique injecté sur toutes les pages.
- [background.js](file:///home/omni/Code/Elearning_Ext/background.js) : Service worker gérant les requêtes réseau, SerpAPI, et l'injection dynamique du cœur à la demande.
- [content.js](file:///home/omni/Code/Elearning_Ext/content.js) : Script injecté dans les pages web de quiz ; observe les mutations et les intersections visibles pour surligner les réponses sans CPU inutile.
- [providers.js](file:///home/omni/Code/Elearning_Ext/providers.js) : Gestion de l'interfaçage des modèles de langage et définition de ConfigCache.
- [schema-detector.js](file:///home/omni/Code/Elearning_Ext/schema-detector.js) & [schema-cache.js](file:///home/omni/Code/Elearning_Ext/schema-cache.js) : Analyseur de structure DOM dynamique qui utilise un LLM pour modéliser le format d'un quiz et le mettre en cache par domaine.
- [settings.html](file:///home/omni/Code/Elearning_Ext/settings.html) / [.js](file:///home/omni/Code/Elearning_Ext/settings.js) / [.css](file:///home/omni/Code/Elearning_Ext/settings.css) : Page de configuration (clés d'API, import de PDF/DOCX pour la base de connaissances/context).
- [popup.html](file:///home/omni/Code/Elearning_Ext/popup.html) / [.js](file:///home/omni/Code/Elearning_Ext/popup.js) / [.css](file:///home/omni/Code/Elearning_Ext/popup.css) : Interface utilisateur rapide de l'extension.
- [randomize_name.js](file:///home/omni/Code/Elearning_Ext/randomize_name.js) : Script Node.js de brouillage de signature (modifie le manifest) pour éviter la détection par empreinte d'extension.
